FENG JIN PORTFOLIO - QUICK EDITS

Before uploading to GitHub, open index.html and replace:

1) YOUR_NETID
   Replace with the NetID shown at the top-right of LearnCS8.

2) LinkedIn URL
   Find: https://www.linkedin.com/
   Replace with your real LinkedIn profile URL.

3) GitHub URL
   Find: https://github.com/
   Replace with your real GitHub profile URL.

4) Email
   Find: YOUR_EMAIL@example.com
   Replace with your real email address.

5) Profile photo
   Replace img/fengjin.jpg with your own photo.
   Keep the SAME filename: fengjin.jpg
   Recommended size: around 250 x 250 or similar.

6) Portfolio images
   Replace:
   img/portfolio1.jpg
   img/portfolio2.jpg
   img/portfolio3.jpg
   img/portfolio4.jpg
   img/portfolio5.jpg
   img/portfolio6.jpg

   Keep the same filenames so you do not need to edit the HTML.

UPLOAD TO GITHUB:
- Create repository: YOURUSERNAME.github.io
- Upload the CONTENTS of this folder, not the outer folder itself.
- Make sure index.html is at the root level.
- Settings > Pages > Deploy from a branch > main > /(root) > Save
